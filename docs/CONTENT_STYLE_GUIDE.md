# Content and photo style

Use short, specific titles and plain language. State what someone needs to attend: confirmed date, Indiana local time, place, any signup, and weather contingencies. Describe events as Tentative when appropriate. Preserve cancelled event pages so previously shared links explain the change.

Automatic phases, oppositions and seasonal events identify their calculation source; meteor dates identify AMS and the check date. Use Automatic Sky Calendar settings to manage them. Never copy astronomy dates out of artwork. Verify them against a credible astronomy source and record the source and verification date. Monthly sky notes need the same verification. Draft examples are formats, not factual announcements.

Every informative image needs alt text describing what is visible. Use captions for context; use credits to identify the photographer. Avoid placing important event details only in a poster image. Keep text in the CMS fields so it remains accessible and updates everywhere.

Obtain permission before publishing photographs or personal information. Check backgrounds for sensitive details, export web copies without location metadata, and retain originals elsewhere. The photo preparation tool is an optional browser-only aid; review its output. Source uploads in GitHub are public even when a content entry is a draft.

The homepage background is a lunar eclipse sequence above Purdue’s campus; the calendar’s default background shows telescopes under the stars. A replacement club photograph should have its own accurate alt text and credit. Do not imply Purdue or a sponsor has endorsed the club unless that relationship is confirmed.
